# Toy Water Shop — Demo App

This is a small demo application built to showcase **toy-router** and **toy-state-manager** working together inside a **vanilla JS + Web Components** setup.

The project demonstrates how easily you can build a simple, fully functional SPA **without any frontend framework**, relying only on:

- custom Web Components
- a minimal client-side router (toy-router)
- a lightweight global store (toy-state-manager)

It’s not a real store — just a clean, practical example of how these tools integrate.

---

## 🚀 Running locally

```
npm install
npm run dev
```

Open the local URL shown by the dev server (Vite recommended).
