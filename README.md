# Toy Water Shop — Demo App

This is a small demo application built to showcase my other projects - [**toy-router**](https://github.com/bartlomiej-bykowy/toy-router) and [**toy-state-manager**](https://github.com/bartlomiej-bykowy/toy-state-manager) - working together inside a **vanilla JS + Web Components** setup.

The project demonstrates how easily you can build a simple, fully functional SPA **without any frontend framework**, relying only on:

- custom Web Components
- a custom client-side router (toy-router)
- a custom state manager (toy-store)

It’s not a "real" store app - just a simple and practical example of how these tools integrate.

---

## 🚀 Running locally

1. Install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

2. Run dev server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open the local URL shown by the dev server (Vite recommended).
